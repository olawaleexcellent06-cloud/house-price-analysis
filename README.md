# 🏡 House Price Analysis

## 📌 Project Overview
This project analyzes residential housing data using Microsoft Excel to identify the key factors influencing property prices.
The project demonstrates the complete data analysis workflow—from data preparation and exploratory analysis to dashboard development and business recommendations.
The analysis focuses on understanding pricing trends, housing market distribution, and the relationship between property characteristics and selling prices.

## 🎯 Business Problem
Understanding what drives property prices is important for real estate companies, investors, and developers when making pricing and investment decisions.
This analysis aims to answer key business questions:
- What is the overall state of the housing market?
- Which property characteristics influence selling prices?
- Which housing categories dominate the market?
- Does property size have a relationship with house value?
- How do different property features affect average prices?

## 🎯 Project Objectives
The main objectives of this project are:
- Analyze residential property price patterns.
- Identify the relationship between property size and selling price.
- Compare average prices across different property categories.
- Understand housing market distribution.
- Create a dashboard that summarizes key findings and insights.

- ## 📂 Dataset
The dataset contains **49,958 residential properties** with the following attributes
- Square Feet
- Bedrooms
- Bathrooms
- Neighborhood
- Year Built
- Selling Price
The dataset was analyzed using Microsoft Excel to identify pricing trends and generate business insights.

## 📈 Key Insights
### Market Overview
- The dataset contains **49,958 residential properties**.
- The average selling price is **$225,015.72**.
- The median selling price is **$225,127.99**, indicating a balanced price distribution.
- The average property size is **2,007 sq ft**.
- The average selling price per square foot is **$113.39**.

### Housing Market Distribution
- Mid-range properties account for approximately **45%** of the market.
- Premium properties represent approximately **38%**.
- Affordable properties account for only **17%** of all homes.

### Property Size Analysis
- Large homes recorded the highest average selling prices.
- Medium-sized properties followed.
- Small properties had the lowest average selling prices.
Property size was identified as one of the strongest drivers of house prices.

### Bedroom & Bathroom Analysis
- Average selling prices generally increased with the number of bedrooms.
- Homes with more bathrooms also recorded higher average selling prices.

### Relationship Analysis
The scatter plot revealed a positive relationship between square footage and selling price, indicating that larger homes generally command higher market values.

## 💡 Business Recommendations
- Focus marketing efforts on mid-range properties since they represent the largest market segment.
- Prioritize larger residential developments because they generate higher average selling prices.
- Consider property size as a primary pricing factor when evaluating residential properties.
- Monitor affordable housing opportunities due to their relatively limited market share.
